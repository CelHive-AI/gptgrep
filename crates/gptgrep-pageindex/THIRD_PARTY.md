# Source provenance

The document-range and conservative bookmark-boundary design was studied from
[VectifyAI/PageIndex](https://github.com/VectifyAI/PageIndex/tree/9c4c3ff2ddd2cbd70501997635578064f2b7c7c3),
revision `9c4c3ff2ddd2cbd70501997635578064f2b7c7c3` (MIT):

- `pageindex/flash/api.py`: Preface and page fallback semantics.
- `pageindex/flash/outline_assembly/assembly.py`: inclusive page ranges and
  parent span promotion.
- `pageindex/flash/embedded_toc.py`: bookmark validation and shared page boundaries.
- `pageindex/tree_optimize.py`: the deterministic optimizer port described below.

The Rust implementation and adapters are GPTgrep-owned. Layout construction is a
partial design adaptation; the separate optimizer translates selected
deterministic algorithms. Neither establishes full PageIndex Flash equivalence.
CommonMark parsing uses the `pulldown-cmark` crate under its upstream license;
serialization uses `serde`. Cargo.lock records resolved dependency versions.

`src/optimizer.rs` maps to pinned `pageindex/tree_optimize.py` as follows:

| Rust behavior | Upstream source lines |
|---|---|
| Inclusive `S`, child-page union, residual pages, worst-case cost | 231–259 |
| Independent frontier formulation used by tests | 262–280 |
| Union titles with 200 Unicode-character limit and page-label fallback | 469–488 |
| Same-span leaf sibling grouping and retained `key_items` | 491–529 |
| Bottom-up collapse with ties merged and descendant titles retained | 533–579 |
| Preorder ID relabeling | 207–224 |
| Deterministic pass ordering | 798–810 |

Documented extensions: GPTgrep validates line coordinates and complete coverage,
requires modern parent-span containment instead of accepting legacy truncated
parent ranges, unions same-span sibling line ranges, preserves any pre-existing
parent `key_items`, and completes merge operators to a fixed point. Upstream's
general optimizer defaults to at most three rounds and also supports LLM
expansion; no expansion code or model call is ported here. The port uses iterative
arena traversal and interval unions rather than recursive trees or per-page sets.

`tests/fixtures/pageindex_merge.json` was generated by executing only selected
pure AST function definitions from that exact source file, SHA-256
`3112940bf4c4e4add0203316575e1426cf06b375a97e67d415129af7c119061a`.
The package was not imported and no model/API request was made. The generator
and fixture source binding are retained beside the JSON. Fixtures are original
small structural cases; no document corpus was copied.
